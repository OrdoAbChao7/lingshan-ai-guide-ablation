# SkyGuard 性能报告

> 数据来源：`evaluation/skyguard/performance.json`
> 生成时间：2026-10-29T11:30:57Z
> 主机：AMD Ryzen 7 7745HX / Windows (win32) / Node v24.19.0
> 复现：`npm run bench:safety --prefix backend`

## 1. 口径说明

本基准只测量**本机单进程计算延迟**，不包含：

- HTTP 网络往返与 Express 中间件开销；
- 前端渲染与轮询开销；
- 视频解码（单独测量于 §4）；
- 昇腾推理（无设备，未测量）。

因此**不得**把这些数字解读为端到端系统响应时间或"昇腾加速"效果。

## 3. 观察

- **演示场景**：一次完整决策闭环（观测评估 → 风险 → 规划 → 校验 → 状态 → 审计写盘）
  p95 为 0.924 ms，远低于任何人工操作节奏；
- **规模扩展**：节点数 99 → 275 → 539（约 5.4×），规划 p50 从 0.39 ms 升到 5.15 ms（约 13×），
  增长快于线性但仍属毫秒级；这是 SPFA 最小费用流的预期特征；
- **审计写盘**包含在 `recompute` 的数字里（JSONL 追加），未单独剥离；
- 上述数字**不含**任何硬件加速。

## 4. 视频感知（未纳入上表，单独实测）

> 这些数字只说明"链路能跑、帧间稳定"，**不构成计数准确率**——合成视频没有真值标注，
> 真实人群视频的准确率未测。

## 5. 未测量的项目

- 200 QPS 级别的并发压力（进程内状态未做并发优化，也未做压测）；
- 长时间运行的内存增长；
