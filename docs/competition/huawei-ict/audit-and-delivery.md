## 新版本的实质改进

新增五工具严格契约、Header API Key、统一错误与 Trace、40 秒超时、有限并发和审计落盘；封装原服务供平台逐节点调用。场景关键冲突与低置信度保留追问；独立校验拦截压缩时间轴、伪造可行标记和未知演出场次。替代方案只放松软偏好，不自动改变硬约束。新增管理员调试界面和开发评测记录。

这些是原版与本分支的代码差异；是否满足既有获奖作品改进要求仍待组织方确认。当前没有对外发送资格咨询，没有登记成员或提交比赛材料。
