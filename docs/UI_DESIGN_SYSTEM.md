# 灵小禅 · 全站 UI 设计系统

> 本文件是**前端全部页面**的视觉与交互契约。改任何页面样式前先读本文件。
> 设计方向由本地 UI 能力检索（`ui-ux-pro-max`：`dark-mode-oled` 风格族 + 深色看板配色档 +
> 无障碍规则）选定后收敛，**不是随手调色**。

## 1. 三个业务域，一套规则

| 域 | 页面 | 色板 | 为什么不同 |
| --- | --- | --- | --- |
| 游客端 visitor | `/`、`/qa`、`/recommend` | 宣纸暖色 + 灵山朱 + 描金 | 面向游客，需要温度与文化气质 |
| 管理后台 admin | `/admin/*` | 宣纸底 + **墨色侧栏** + 描金发丝线 | 面向运营，需要信息密度与稳定空间记忆 |
| 安全大屏 ops | `/command-center` | 深色 OLED + 四态语义色 | 值班场景长时间凝视、低环境光 |

**共享的是规则，不是色值**：字号阶梯、间距节奏、圆角、焦点环、对比度下限、图标规范、
动效约束、诚实性约束全部一致；色板按场景各自定义，互不污染。

## 2. 令牌层（唯一来源）

| 文件 | 内容 |
| --- | --- |
| `frontend/src/styles/tokens.css` | primitives + semantic：品牌色、表面、文本、线条、语义色、圆角、间距、字号、阴影、动效 |
| `frontend/src/styles/ui.css` | 跨页面组件：面板 / 统计 / 列表行 / 标签 / 说明 / 空态 / 后台壳层 / antd 归一化 |
| `frontend/src/index.css` | 只保留全局重置、排版基线、滚动条 |

规则：

1. **页面 CSS 不写裸色值**，一律 `var(--…)`；确需新色先加到 `tokens.css` 并注明对比度。
2. **组件类只在 `ui.css` 定义一次**，页面私有类写在各自的 `*Page.css`。
3. **不使用全局裸选择器**（旧版裸 `button {}` 会污染其他页面，已清理）。

### 文本对比度（实测，对白底 / 纸底）

| 令牌 | 值 | 白底 | 纸底 | 用途 |
| --- | --- | --- | --- | --- |
| `--text-1` | `#241c18` | 16.7:1 | 15.6:1 | 正文/标题 |
| `--text-2` | `#5b5148` | 7.7:1 | 7.1:1 | 次级正文 |
| `--text-3` | `#6d6259` | 5.9:1 | 5.4:1 | 元数据（最低档） |
| `--ok` | `#1f7a52` | 5.3:1 | 4.9:1 | 成功语义文字 |
| `--warn` | `#8a6a2f` | 5.0:1 | 4.6:1 | 警示语义文字 |
| `--danger` | `#c0392b` | 5.4:1 | 5.0:1 | 危险语义文字 |

## 3. 字号与间距

字号固定 8 档：`11 / 12 / 13 / 14 / 16 / 20 / 26 / 34`，禁止游离数值。
间距固定 8px 节奏：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
圆角四档：`6 / 10 / 14 / 18`（+ `999` 胶囊）。
数字与编号一律等宽 + `tabular-nums`（`--font-mono`）。

## 4. 管理后台壳层（`components/admin/AdminShell.tsx`）

```text
┌ 侧栏 232px（墨色） ┬ 顶栏 60px（白，sticky，标题+副标题+操作区） ┐
│ 品牌标记 + 名称    │                                                │
│ 运营：概览/知识库/ │  内容区 max-width 1520，24px 留白，16px 间距    │
│      数字人/感受度 │                                                │
│ 安全：SkyGuard 大屏│                                                │
│ 底部：返回游客端   │                                                │
│      退出登录      │                                                │
└────────────────────┴────────────────────────────────────────────────┘
```

* 导航项同时给出 `aria-current="page"`；侧栏在 ≤900px 折叠为顶部横向导航。
* 页面标题、副标题、页面级操作（导出、刷新、周期切换）**统一放顶栏**，
  不要在页面内容区再造一个二级标题栏——这是四个后台页面视觉一致的根因。

## 5. 组件规格

| 组件 | 规格 |
| --- | --- |
| 面板 `.ui-panel` | 白底、1px 发丝线、14 圆角、`--shadow-1`，内距 16/24 |
| 面板头 | `eyebrow`（等宽大写 + 描金）+ 标题 + 副标题 + 右侧操作，下接发丝线 |
| 统计块 `.ui-stat` | 左侧 2px 描金条、等宽大数字 26px、无边框噪音 |
| 列表行 `.ui-list-row` | 序号徽标 + 主文 + 等宽元数据，行间仅一条发丝线 |
| 标签 `.ui-tag` | 20px 高、6 圆角、语义色描边 + 8~12% 底色 |
| 按钮 | 后台 32px、圆角 10；游客端主行动按钮可到 40–48px |
| 焦点态 | `2px` 品牌红 outline + `2px` offset（深色域用蓝 `#5a9bff`） |

## 6. 图标规范

* **禁止 emoji 充当结构性图标**（字体依赖、无法着色、跨平台不一致）。
* 结构图标：后台/游客端用 `@ant-design/icons`（同一线性风格）；安全大屏用自绘
  `components/…/icons.tsx`（24×24、1.6 描边、`currentColor`）。
* 品牌标记统一为 `components/brand/LingMark.tsx`（三阶塔檐几何路径），
  替换了原来的 `🏯` emoji，登录页/侧栏/游客端顶栏/数字人兜底共用。
* 装饰性图标 `aria-hidden`；独立可交互图标按钮必须有可访问名称。
* 聊天正文里的 emoji 属于**内容**而非图标，允许保留。

## 7. 无障碍与诚实性约束

1. **不靠颜色**：状态同时给文字（如 `正常/关注/高风险`、`通过/未通过`）。
2. **不靠动效**：`prefers-reduced-motion: reduce` 下关闭流动、呼吸与过渡。
3. **不靠悬停**：图表与图元带 `title` / 可读文本；表格列有表头作用域。
4. **不美化不确定**：`estimated` / `uncalibrated` / `unverified` 原样呈现，
   不用绿色或其他"看起来正常"的样式包装。
5. **不改写历史**：审计时间线只读；页面不提供编辑/删除历史记录的入口。
6. **空态要说明原因**，不只写"暂无数据"。

## 8. 安全大屏（ops 域）补充约束

| 状态 | 令牌 | 色值 | 可用动作 |
| --- | --- | --- | --- |
| `NORMAL` | `--sg-ok` | `#2FD08A` | 可发布、可显示已验证路线 |
| `REROUTE` | `--sg-info` | `#5A9BFF` | 可发布新方案 |
| `DEGRADED` | `--sg-warn` | `#F0B429` | 只显示降级原因，**不显示路线** |
| `REJECT` | `--sg-danger` | `#FF6B6B` | 只显示候选方案 + 违规原因 |

铁律：`REJECT` 下不得出现绿色路线；`DEGRADED` 下不得出现任何路线；
发光是稀缺资源，只用于状态徽标与已验证路线。大屏令牌在
`CommandCenterPage.css` 内自带 `--sg-*`，与浅色域完全隔离。
